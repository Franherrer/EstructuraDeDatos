## Cómo ejecutar

1. Clonar el repositorio:

```bash
git clone <enlace-del-repositorio>
```

2. Entrar a la carpeta `src` del proyecto:

```bash
cd <nombre-del-repositorio>/src
```

3. Compilar:

```bash
javac Metodos_de_ordenamiento/*.java
```

4. Ejecutar cada programa:

```bash
java Metodos_de_ordenamiento.MainQuick
java Metodos_de_ordenamiento.MainShell
```

También se pueden correr desde IntelliJ IDEA: clic derecho sobre `MainQuick` o `MainShell` y **Run**.

** nota ** opte por meter shellsort en una carpeta aparte para diferenciar esta practica y poder adjuntar su propio readme de ejecucion
